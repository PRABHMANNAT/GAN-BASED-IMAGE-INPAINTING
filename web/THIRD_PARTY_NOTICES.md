# Third-party components

## Pretrained MI-GAN model

`public/models/migan.onnx` is the MI-GAN-512-Places2 pipeline v2 published by the model authors:

- Project: https://github.com/Picsart-AI-Research/MI-GAN
- Download: https://huggingface.co/andraniksargsyan/migan/resolve/main/migan_pipeline_v2.onnx
- Authors: Andranik Sargsyan, Shant Navasardyan, Xingqian Xu and Humphrey Shi; Picsart AI Research.
- Paper: *MI-GAN: A Simple Baseline for Image Inpainting on Mobile Devices*, ICCV 2023, pp. 7335–7345.
- Training dataset: Places2, as documented by the authors.
- Weights license: MIT, Copyright (c) 2024 Picsart AI Research (PAIR). Full notice is redistributed in `public/models/MI-GAN-LICENSE.txt`.
- SHA-256 and model provenance: `public/models/migan-provenance.json`.

This pretrained model is an added repair option. It is not the EdgeAwareGAN from the user's supplied report, and it was not trained by this project. The separate `edge-unet.onnx` is the project's own synthetic-illustration teaching generator, with its export and training provenance beside it.

## Runtime and interface dependencies

Runtime files are copied by the build from the locked npm dependencies; original license files are copied into `public/runtime/licenses/` at build time.

- ONNX Runtime Web — Microsoft; MIT license. https://github.com/microsoft/onnxruntime
- OpenCV.js — OpenCV contributors; Apache-2.0 license, distributed through `@techstark/opencv-js`. Used for Canny edges and morphological scratch detection, not classical `inpaint` (that binding is absent from this distribution). https://github.com/TechStark/opencv-js
- Lucide icons — ISC license. https://lucide.dev/license
- Vite — MIT license. https://github.com/vitejs/vite

The browser's fast context-fill routine is an original distance-ordered weighted-neighbour implementation. It does not claim to reproduce OpenCV Telea or Navier–Stokes. The original Python demo retains its actual OpenCV Telea baseline.

The facade and coast images are original procedural illustrations generated by `scripts/make_samples.py`. No third-party photographs, remote fonts or hosted image assets are required.
